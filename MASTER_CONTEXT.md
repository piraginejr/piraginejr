# MASTER CONTEXT — POWER CHURCH

## Objetivo do sistema
Sistema Power Church para gestão ministerial, financeira, OCR de envelopes, importações bancárias, gestão de membros e automações administrativas da igreja.

## Stack principal
- Python
- Django
- Docker
- SQLite

## Funcionalidades principais
- Gestão de membros
- Importações bancárias
- OCR de envelopes
- Financeiro
- Relatórios

## Regras importantes
- Não subir bancos de dados para GitHub
- Preservar compatibilidade Docker
- Não quebrar parser bancário
- Preservar OCR existente

## Pastas principais
- power_church_core
- power_church_django
- scripts
- reports
- data

## Áreas críticas
- parser bancário
- matching PIX
- OCR de envelopes

## Objetivos futuros
- estabilizar OCR
- melhorar matching automático
- melhorar performance
